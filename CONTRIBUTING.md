# Contributing

This repository accepts no pull requests and no issues. The reason is
structural: the method's semantics live upstream in
`mithran-hq/aegis-method` and arrive here by distillation. A pull request
against this repo would fork text that is maintained somewhere else, and a
fork of the payload is a different, unmeasured payload.

The full Aegis Method — the specification, the engine, the enforcement
layer — launches soon. That repository is where contribution energy belongs.

Until then, the license is MIT: fork it, paste it, adapt it, benchmark it.
If you change the payload text, treat your results as unmeasured; the numbers
in `evidence/` describe the text exactly as shipped here.
